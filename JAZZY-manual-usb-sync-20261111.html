FIELD MANUAL / FM–1

A world of sound awaits.

Start with one track. Play a phrase, then try it on a few engines. When a sound makes you want to keep playing, mark it as a favorite so you can find it again.

First sound

  1. Use ALGORITHM to choose the active track.
  2. Tap EDIT to enter the remembered EDIT page. Tap again to advance one page. SELECT goes forward or back through the same visible pages.
  3. In EDIT → SOUND → PRESETS, turn K2 to pick an engine and K1 to audition its sounds. Play a note and try the engine controls on EDIT 1 and EDIT 2.

The preset browser

  • K1 PRESET auditions sounds in the current list. K2 ENG switches to another engine.
  • K3 FAV adds a star clockwise and removes it counterclockwise. K4 LIST filters by favorites or by type such as BASS, LEAD and PAD.
  • On EDIT’s PRESETS page, the dedicated PRESETS knob follows that engine and filter. On other EDIT pages and HOME it scrolls the whole catalog. In SEQ it opens the pattern phrases.
  • SAVE → SOUND → PRESETS shows sounds across engines and keeps the browser filter.

Shape and animate

Set attack, decay, sustain and release in ENV. Watch the skater follow the note. LFO provides two independent modulators, destinations, phase controls and a motion sequencer. In FX, set each track’s sends, then adjust the delay, reverb or chorus bus on its own page.

Repeated FX, ENV and LFO taps visit their individual pages. Set DARK or LIGHT in the display menu, or switch animation off there.

Sidechain ducking and Kick Link

Press FX to reach MASTER, then turn SELECT to DUCK. Choose the trigger with SRC.

  • AUTO follows recognized internal kicks or incoming Kick Link. JAZZY recognizes KW KICK and Hortator kick models. For LXR, use K2 LXR KICK to assign the kick track. OFF leaves LXR out of AUTO and outgoing Kick Link.
  • T1–T6 follows the audio level of the selected track. That source track stays at its own level. Use THR to set the trigger threshold.
  • USB follows incoming USB audio above THR. Use USB Device mode, enable input in MENU → USB → USB AUDIO, and route an isolated audio feed from a USB host such as a computer.
  • MIDI triggers from a matching Note On. Set CH to ANY or 1–16, and NOTE to the trigger pitch (default 36). Any positive velocity triggers the same envelope. The matching Note On is consumed as a trigger.

Turn SELECT to DUCK ENV. ATK controls how quickly the gain drops, REL controls the return, and AMT controls the depth. AMT and MASTER → DUCK share one value. At zero amount, there is no ducking. Save the section to keep these settings.

Connect JAZZY and RHYTHMER

For tempo and transport sync, see Sync two FM‑1s over USB.

  1. Use a USB host adapter and a data cable to connect the two FM‑1s. Enable MENU → USB → USB HOST on one FM‑1 and leave the other in Device mode.
  2. On the unit playing the kick, set MENU → MIDI → MIDI OUT → KICK LINK.
  3. On the receiving unit, choose FX → MASTER → DUCK → SRC = AUTO, then raise DUCK ENV → AMT. A qualifying local kick has priority for two beats.

Drums and Break

Each HORTATOR, LXR or KW KICK sound occupies one track. LXR's 595 sounds are ordered as 85 sets with seven voices each, from drum voices and snare to cymbal and closed and open hats.

BREAK ships with A / Amen and B / Think. Open EDIT → BREAK for performance, sequencing and return controls. SEQ → BREAK brings the loop and slice events into the step workflow.

Sequence and GEN

Use SEQ to move through pattern, track, step, automation and engine-specific pages. Hold HOME and turn SELECT to open GEN. Choose a style and use OCT+ to generate a starting point with musical roles such as bass, chords, lead and arpeggio.

HORTATOR, KW KICK and LXR also expose SEQ → GEN for one-track Euclidean, Mutate, Turing, Cellular and Grids patterns.

Save and switch projects

SAVE groups the library into SONG → PROJECT → SOUND. Open PROJECTS to switch projects, SECTIONS to work with A–D, and USER to save a sound.

In PROJECT → CLEAR, K1 selects the project and K2 the section. K3 selects section clear and K4 whole-project clear. OCT+ opens the review, and a second OCT+ executes the selected clear.

USB MIDI

JAZZY starts in USB Device mode. To use a compatible MIDI controller, stop playback and open MENU → USB → USB HOST, then confirm with OCT+. Host mode lasts for that session. Use external power for a controller that needs USB bus power.

Sync two FM‑1s over USB

Example: RHYTHMER sets the tempo and JAZZY follows.

  1. Stop both FM-1s. On JAZZY, set MENU → USB → USB HOST to ON and confirm with OCT+. Leave RHYTHMER in USB Device mode.
  2. Connect the FM-1s with a USB data cable through an externally powered USB host hub or adapter on the JAZZY side. The FM-1 host port does not supply USB bus power. Wait for USB MIDI CONNECTED on JAZZY.
  3. On RHYTHMER, set GLO → GLOBAL → CLOCK to INT and MENU → MIDI → MIDI OUT to CLOCK. Set the tempo on RHYTHMER.
  4. On JAZZY, set GLO → GLOBAL → CLOCK to USB and MENU → MIDI → MIDI OUT to OFF.
  5. Press PLAY on RHYTHMER. JAZZY follows its tempo and start/stop commands. To check timing, try 120 BPM and listen to both patterns for several bars.

USB Host is the connection role. In this example JAZZY hosts the cable while RHYTHMER leads the tempo. Enable Host again after restarting JAZZY.

On current builds, CLOCK and KICK LINK are separate MIDI OUT modes. Use CLOCK on RHYTHMER for this example.

Use Samples to replace either Break slot, and Save for Play + Audio to export a complete .fm1save for Web Play. In USB FM-1 mode, connect a device running the matching JAZZY firmware in Chrome or Edge.
