RHYTHMER / READ-ONLY CHECK

CHECK THE RUNNING FIRMWARE.

This checks the FM-1 identity, Rhythmer editor layout and the firmware’s A/B bank-validity flags. It does not install, restart, load a project or write a sample.

Use this after the beta3 installer’s old development-name check stopped at 94%. The original failed report remains a record of that check; this is a separate inspection.

Connect one FM-1. No device write will be performed.

This is not a full firmware-byte readback or a physical recovery test. Test playback and controls separately.
