# Rhythmer v0.1.1-beta3 — build 20261108.9

Startup and product-copy maintenance. The boot screen always shows animated DRUM / ANALOG / PHASE / LOFI / ACID / BREAK identities, regardless of actual sounds, empty slots or four-/six-track mode. A pixel-assembled Rhythmer wordmark, rhythmic rail and “Sound into motion / Find your own groove” complete a bounded 2.1-second sequence. ANIM OFF keeps it still. Actual T2 defaults to WAVETABLE as before. Only ui_draw.c and the About product line in ui_menu.c changed from build 20261108.8; audio DSP, buffer, voice management, core scheduling, track assignment and sequencing are unchanged.

Includes native Hortator Acid and restored buffer headroom. The version label is unchanged; identify this maintenance revision by build and SHA-256.

- Acid is now a native Hortator synth with all four sounds. X0X audio DSP/model/parameter state is removed; its TB-3PO NEW/MUTATE MIDI generation remains separate.
- The creator installed build 20261108.6 and reports very good, stable playback without the earlier buffering issue. This revision keeps that audio DSP, 512-frame half-buffer, JIANT voice/CPU policy and new-engine dual-core scheduling.
- Fresh settings start in four-track mode. GLO → SYSTEM → 6 TRACK MODE shows the CPU notice; OCT+ confirms and OCT− cancels. Confirmation fills empty T5 with Acid and empty T6 with Break. Existing sounds and MIDI are preserved. A Break assigned elsewhere is never duplicated. No automatic sequence is written.
- EMPTY / SELECT ENGINE no longer appears while browsing sounds with PRESETS. EMPTY remains available for explicit engine selection, and turning PRESETS from EMPTY starts with a real sound.
- Fresh shared SCL starts in CHR; Acid GEN 2 displays and uses the same ROOT/SCALE. Existing saved scales remain unchanged.
- ALL LOOP/PARTS/SONG uses active slots and keeps existing Acid/Break parts. Only the existing named SR_ACID recipe assigns native Acid, for mono bass. Ordinary bass, melody and chord sound pools exclude it; automatic Break assignment remains excluded.
- Brief drum attack protection; tails use ordinary shared management without a separate MD cap. FM6/MD state shares safe per-track memory. Exact-silence Break optimization retains clocks and immediate wake behavior.
- Corrected, level-matched Think and Amen are integrated in the one-step firmware package. User sample preparation/upload, four-project editor storage, dual LFOs and the updated English manual are included.

Host regressions, actual-firmware emulator/USB playback, editor, uploader and installer simulation are recorded in RELEASE-VALIDATION.json. Owner audio-base listening and final automated checks are recorded separately. Dense six-track arrangements can still exceed the hardware budget: mute tracks or reduce simultaneous voices/effects if needed.
