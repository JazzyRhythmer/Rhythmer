# v0.1.1-beta3 — build 20261107.2

The version label is unchanged for this maintenance revision. Verify the package SHA-256 in the installer.

- 59 GEN genres, including the ten new house, hip-hop and IDM profiles. Curated presets retain their tuning; bass and chord sound selection follows the musical role. More deliberate harmony and melodic space.
- ALL creates T1–T4 only, including macro routes. T5/T6 settings and notes stay intact. Explicit track MIDI targets and genre-aware BREAK GEN remain available.
- Complete Hortator MD bank: 55 presets, per-lane sound replacement and 19 kits with two experimental MD LAB kits. Four Hortator Acid sounds alongside X0X.
- Empty initial sequences with A / Amen selected; corrected, level-matched Think.
- Guided two-bar sample crop, source BPM, conversion, preview and confirmation in the web editor. Four-project musical backups and SAVE FOR PLAY remain available.
- Detailed 15-section English manual, especially Acid generation, Break sequencing/performance and own-sample upload.
- Rhythmer INFO/version/USB branding; renamed rhythmer source and upstream-editor/upstream-installer reference folders. Original licensing and credits retained. Installer accepts the reviewed legacy same-version INFO as well as the current name.
- Shared Phaser integer DSP and streamlined Break processing. Existing dual-core scheduler, clocks, synchronization and ordinary voice budget remain. All memory protection reserves pass.

Automated validation: 45 actual-firmware emulator runs, 576 genre seeds, 354 MIDI targets, 177 ALL preservation cases, 144,000 PCM12 cases, 59 C/WASM editor checks, 30 sample checks and 48 simulated installer checks. See RELEASE-VALIDATION.json for the exact hash and test scope.

The exact revised binary still needs physical sustained-load listening. The owner reported overload on an earlier same-version build in a dense six-track song. Emulator timings do not reproduce all real-device flash-cache contention. Back up before installing; keep CPU headroom. Use official V15 when changing firmware families and keep USB/power connected through completion.

Bundled Amen/Think recording rights remain separate from the software license; redistribution permission is not documented. Credits and installation acknowledgements are not a blanket license. Users can replace both samples in the editor.
