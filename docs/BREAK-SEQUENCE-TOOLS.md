# Break sequence authors and automation

Select the track assigned to BREAK and hold SEQ. This works from HOME, EDIT and sequence pages; other machines keep their original SEQ layer. Releasing SEQ restores the normal keyboard. The held keys are UI commands, never auditioned or recorded as notes. PLAY and the existing REC/SEQ combination retain their JIANT behavior.

| White key | Action |
| --- | --- |
| F3 | STRAIGHT: 32 sixteenth steps, C1–C16 in order with a TIE after each chop. Two bars; CHOP source; straight timing and full gate. |
| G3 | MUTATE: change some off-beat chops, retaining quarter-note anchors and source-only commands. |
| A3 | RANDOM: generate a new chop order; AMOUNT controls added sixteenth hits. The opening downbeat is retained. |
| B3 | FILL: replace the tail with a slice followed by existing 1/16 and 1/32 repeat/up/down/shrink commands. |
| C4 | SHUFFLE: reorder complete four-step beats, preserving their internal events and the opening beat. Recorded motion moves with the events. |
| D4 | REVERSE: reverse event order, preserving note/tie groups. This is sequence order, not reversed sample audio. |
| E4 / F4 | SHIFT left / right by one step, with the events' recorded motion. |
| G4 | A/B SEQ: source A at the pattern start, B at its midpoint. These are visible, editable source commands. A full four-command destination is rejected before rewriting it. |
| A4 / B4 | Select loaded sample A / B. |
| C5 | CLEAR the selected sequence inside LEN. |
| D5 | REVERT the selected track using the available JIANT mutation anchor. |
| E5 | CLR MOTION: clear this track's recorded automation and locks. Use the black OFF key to disable pattern generation. |
| G5 | Existing CLR STEP command. |

## Saved automatic variations

While SEQ is held, knobs 1–4 edit LEN, AMOUNT, EVERY and AUTO ACT. EVERY offers OFF or 1/2/4/8/16/32 global bars. AUTO ACT offers MUTATE, FILL or RANDOM. Black keys provide OFF, 2/4/8/16 bars, those three actions, and ORBIT/DRIFT. Enabling an interval on an empty pattern starts a two-bar straight sequence. A first action with an unset amount starts at 25%.

ORBIT uses JIANT's captured starting pattern; DRIFT varies the latest pattern. Changes use its existing bar scheduler, once per eligible boundary. FILL refreshes the tail at the interval; that authored tail repeats with its sequence until updated. It is not a momentary one-off fill. Break FREEZE pauses automatic edits. An empty sequence remains empty under the scheduler. Turning automation off can offer JIANT's existing return-to-anchor choice.

The interval, action, amount, mode and generated events are project data. The original root/scale-independent Break command range is preserved: slices 0–15, performance commands 16–31, A/B 32–33 and return 34. Randomization preserves existing A/B and return commands; per-step sound locks remain unless explicitly cleared. Sound controls, track levels, tempo and other tracks are not regenerated by these tools. STRAIGHT explicitly sets its own length, division, swing and gate to reconstruct the two-bar source.

## Reference decisions

- [Audiomodern Loopmix manual](https://d3jxl5cc6pcqb4.cloudfront.net/Manuals/Audiomodern_Loopmix_User_Manual.pdf), sequencer and randomization sections: different variation strengths, protected material and periodic regeneration informed the separation between MUTATE and RANDOM and the saved interval controls.
- [Audio Damage Replicant 3](https://www.audiodamage.com/products/ad056-replicant-3): sequencing repeat events and controlled variation informed the tail-fill author, using Rhythmer's existing Amenity performance commands.
- [Renoise effect commands](https://tutorials.renoise.com/wiki/Pattern_Effect_Commands), Breakbeat Tricks: sample offsets and retriggers informed editing visible commands in the ordinary sequencer rather than a separate hidden playback pattern.

These are workflow references. This implementation is original GPL project code and uses no proprietary plugin code or assets.

## Resource and validation scope

All generators run in the main loop and touch at most 64 steps. They share the existing sequence-tool scratch and JIANT mutation anchor/scheduler. There is no new sample buffer, synthesis voice, project-format field count or audio-ISR DSP stage. The existing unused Break lane slot P_LN1 holds the action; P_MPAT/P_MAMT/P_MMODE hold the existing automation settings. The browser data engine shares the generator source and new parameter descriptors.

Host checks cover the held gesture, labels, command bounds at all 1–64 step lengths, anchors, A/B preservation, saved settings, automatic scheduling, FREEZE and other-track isolation. Candidate-specific emulator tests cover actual PCM output, automatic changes and the physical-key layer. Physical operation remains a separate user test; this workflow does not flash hardware or publish externally.
