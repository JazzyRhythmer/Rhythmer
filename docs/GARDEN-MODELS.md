# Garden models in Rhythmer

Pinned source: [Garden-FM 3e6821b](https://github.com/nvhhh/Garden-FM/tree/3e6821b87a460e74b7b05545701f924bb9eb9359). Wavetable/Phase/LoFi engine files and their preset arrays are byte-identical to this source revision. Phase and LoFi were already present in the JIANT tree: the former is retained without duplication and the latter is re-enabled. The complete Wavetable engine and its 8-frame wavetable are now included. No presets were removed to make room.

The synth list is Wavetable, Phase, LoFi, FM+STAT, SWAV-SAW, SID-6581, Analog, FM6, Wheel. All models can be assigned freely; Acid allows multiple instances and Break allows only one.

## Note-reactive graphics

Accepted note-on publishes a timestamp and velocity to a tiny UI-only event mailbox. A 280 ms decaying impulse boosts the machine's envelope-based visual level, retriggers per note and advances the graphic phase at a velocity-dependent rate. Wave amplitude expands from a quiet 10% to an active 40% of its drawing region. FM operators expand further; Wavetable depicts its actual wavetable/warp shape, Phase keeps its distortion trace, and LoFi uses quantized chip steps. ANIM OFF suppresses the impulse and decorative phase movement. Existing 80/160 ms display limits remain, with 160 ms for six-machine HOME playback. No audio is generated by the display code.

## Memory and validation

The current image and RAM/pool measurements are recorded in [current validation](CURRENT-VALIDATION.md). Both two-bar break samples, four complete projects, two LFOs, X0X generation, Amenity performance and dual-core dispatch are retained. Existing linker/code-reach/register-access checks and the 8 KiB pool reserve remain enabled. Final package hash, strict timing counters and browser checks are in [current validation](CURRENT-VALIDATION.md). Physical FM-1 behavior remains untested.

Host checks exercise every one of the 41 Garden presets for bounded non-silent output and a project round trip, plus Wavetable filter/resonance/sub cases and note-trigger/velocity/decay behavior. Actual firmware is tested at 240 MHz with the default Wavetable/Phase/LoFi trio, with all three synths changed to Wavetable, and with USB audio. The live test fixture uses lower FX sends for browser audition; the separate stress cases retain all FX sends.
