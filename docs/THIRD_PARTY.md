# SIX current integration sources

Current firmware lives in `jiant/`. Root `firmware/six` is an earlier X0X-based prototype. Pins are recorded in `upstream-lock.json`.

- JIANT: https://github.com/juanjiant-bit/JIANT — current platform/HAL, dual-core scheduler, UI navigation, sequencer and DICE, scale/chord/ARP, song/section/arranger storage, ANALOG/FM6/PHASE/WHEEL/DRUM-X and FX. Original notices, LICENSING.md and LICENSES remain under jiant/. Local changes fix track roles, support four complete projects, adapt memory/voice budgets and add dedicated integration pages.
- X0X: https://github.com/charlesvestal/fm1-x0x — bass303 DSP and TB-3PO generator. Copied source and SPDX notices remain under jiant/firmware/six/. six303_bridge.c isolates the original generator model from JIANT's types.
- Amenity: https://github.com/ejtb76/amenity — Jungle DSP, pattern/roll/one-shot/freeze/straight/auto-roll logic. Original notices are retained. Local adaptation reads packed PCM12 and takes timing from JIANT. The UI maps the same main knobs and physical performance keys into the JIANT workflow. The format/upload unit tests retain synthesized fixtures. The local emulator demonstration now uses the original Amenity Amen sample and a Think sample; these recordings are not covered by the firmware code license. See BREAK-SAMPLES.md for credits and exact preparation.
- Phaser: new four-stage allpass implementation in JIANT's former chorus bus; control coefficients are calculated per block and ramped per sample. Track DIST and the common master CLIP are JIANT implementations. This is not an extra chorus-plus-phaser bus.
- SDK boot files are obtained by the pinned upstream build procedure (AC79NN_SDK_V1.2.1_2023-12-13). SDK artifacts are not vendored into the source tree.

This local integration is not endorsed by the upstream maintainers. No GitHub push, remote release or public upload has been performed.


Garden-FM engine integration is pinned to [3e6821b87a460e74b7b05545701f924bb9eb9359](https://github.com/nvhhh/Garden-FM/tree/3e6821b87a460e74b7b05545701f924bb9eb9359). `eng_serum.c`, `serum_tables.c`, `tools/gen_serum_waves.py` and its host DSP test are retained with GPL-3.0 notices. The existing `eng_phase.c` and `eng_lofi.c` are byte-identical to that revision; Phase remains one engine and LoFi is re-enabled. All upstream preset rows remain unchanged: Serum 8, Phase 16, LoFi 17. Garden's UI art and animations are not imported; Rhythmer draws its own note-reactive geometric views.

Rhythmer engine IDs 15 (Break) and 16 (Acid) stay fixed. Serum is appended as 17. Favorites use spare retired rows for Serum/LoFi, preserving Acid/Break favorites and the machine-toggle metadata. Default synth tracks are Serum, Phase and LoFi; Analog, FM6 and Wheel remain selectable. GEN favors the new models and keeps its first-four-track scope; musical chip presets are favored over byte/float recipes in generated arrangements, while every LoFi preset remains manually selectable.

MONO2K integration is pinned to [ecb3b96c65d9fa92b258923df6317e5bb0ef6b4d](https://github.com/InigoHernandez/mono2k/tree/ecb3b96c65d9fa92b258923df6317e5bb0ef6b4d), by Iñigo Hernández, GPL-3.0-only. Selected FM+STAT, SWAV-SAW and SID-6581 machine kernels and their required tables are adapted in `jiant/firmware/src/eng_mono2k.c` and `jiant/firmware/mono2k/tables.h`; its license is retained alongside. These are MONO2K's clean-room designs, not Elektron ROM code. Rhythmer retains its own ADSR, sequencer, track filter, effects and dual-core scheduler. The 17 starting presets adapt MONO2K SYN settings to Rhythmer; they do not duplicate the full MONO2K chain or factory patch behavior. SID MSRC uses the previous track's stored sequence note at control rate, rather than sharing mutable voice state across cores. Engine IDs 18/19/20 are appended; favorites use retired rows 8/9/11, preserving row 15 settings metadata.

TB-3PO's original six-scale API remains available. A Rhythmer-specific mask API reuses the rhythmic and random laws with the 16 JIANT SCL masks, including 8/12-degree scales. Its degree table is local to the call. New/MUTATE follow SCL ROOT/SCALE; new projects start in MIN. A persisted explicit-choice marker in the Acid track's former generator SCALE slot preserves an explicitly chosen C CHR and prevents treating it as an untouched legacy default. Project structure and stored engine IDs remain stable.

Hortator MD percussion is pinned to [44c9ad4aa57bebf63f412bd552e57143c30b4065](https://github.com/DeadActive/hortator/tree/44c9ad4aa57bebf63f412bd552e57143c30b4065). All 21 MD synthesis models are adapted in `drum_md.c` / `md_*_kernels.h`; import procedure `tools/six/import_hortator_md.py`. Per-model oscillator scratch lives inside the state union, not in every ordinary drum lane. Four hits per track use fixed memory; excess hits hand off with a 32-sample fade. Tune, decay and three named controls fit the existing 11-byte lane A/B schema; other original controls remain at factory settings. This does not import Hortator's entire firmware, banks, UI or sample pack. Copyright DEADACTIVE and original upstream notices remain. Mutable Instruments math is accompanied by its MIT notice.
