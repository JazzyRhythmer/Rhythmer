# Rhythmer media

Sound into motion. A hands-on groovebox firmware for the FM-1, with up to six assignable tracks.

- [Update / 68 seconds](https://jazzyrhythmer.github.io/Rhythmer/assets/updates/rhythmer-update-68s-youtube.mp4)
- [Update / vertical 52 seconds](https://jazzyrhythmer.github.io/Rhythmer/assets/updates/rhythmer-update-52s-instagram.mp4)
- [Manual / 64 seconds](https://jazzyrhythmer.github.io/Rhythmer/assets/video/rhythmer-manual-tour-64s-landscape.mp4)
- [Manual / vertical 64 seconds](https://jazzyrhythmer.github.io/Rhythmer/assets/video/rhythmer-manual-tour-64s-vertical.mp4)

The update demonstrates individual drum replacement, new genres, targeted MIDI, genre-aware Break GEN and user sample preparation. The manual starts with a reading recommendation and explains four-track defaults, six-track activation and the CPU notice, scale-linked Acid, genre-aware Break GEN and held-SEQ shortcuts.

Actual host-rendered firmware UI and the current web manual are used. All four films retain the original AAC soundtrack bitstream; the music is an original atmospheric breakbeat score, not a direct FM-1 recording. This media refresh does not change or validate the firmware binary. Upstream credits remain on the website and in the repository.
