# Firmware UI motion previews

Host-rendered from the Rhythmer firmware UI with note, envelope and preset input. These are silent UI demonstrations, not physical FM-1 footage, hardware validation or audio recordings. FM6 cycles patches to show operator networks. Each capture contains 48 frames at 80 ms per frame. The underlying firmware source is unchanged from the published package.

Capture sources: tools/six/capture_web_motion.c and tools/six/render_web_motion.py. The host display uses the real firmware renderer with a stub LCD. Prepared Amen/Think banks supply the Break waveform graphics. Read THIRD-PARTY-AUDIO.txt for their separate recording rights.
