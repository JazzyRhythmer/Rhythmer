# Rhythmer launch plan

Status: public repository, beta release and website are verified. Copy below remains unsent. Start promotion after the exact-release hardware scope and known power-interruption risk are clearly disclosed; coordinate hub listing with its operator. No campaign start date is set. All visitor-facing copy is English. No paid campaign, automatic outreach, posts or messages are scheduled by this document.

## Positioning

**SOUND INTO MOTION.**

A hands-on groovebox firmware for the FM-1. Shape sounds, build patterns, and find your own groove.

The strongest demonstration is a complete groove: synthesized drums and musical synths, a generated acid line, then break chops that can be edited and saved. Lead with the sound and the real device. Treat the browser version as an easy first encounter and Ko-fi as optional support.

Three audiences: existing FM-1 players looking for a playable sequencer; jungle/breakbeat and acid producers; small-hardware and open-source music communities. Make clear that this is independent community firmware. Avoid a vendor partnership claim, an Elektron product comparison framed as equivalence, claims of zero latency or universal stability, or a blanket sample-use license.

GitHub downloads are not installations. Stars and views are not active users. Do not add tracking scripts to the site by default.

At D+14 review bugs and installation friction before adding more engines. Set numeric targets only after observing a baseline; no audience-growth or donation forecast is implied.

Priority: functioning public links → clear demo → backup/install guide → hub listing → feature clips → refinements. Keep the firmware, rather than the maker's biography or donation request, as the main story.
